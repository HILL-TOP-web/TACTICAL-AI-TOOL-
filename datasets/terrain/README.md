# Terrain Datasets

This directory contains terrain-related datasets used by Tactical AI.

## Purpose

Terrain data can be used for:

- Elevation analysis
- Slope analysis
- Land-cover classification
- Terrain difficulty estimation
- Mobility analysis
- Obstacle identification
- Route simulation
- Geographic environment modeling

## Expected Data

Examples of supported data:

- Digital elevation data
- Land-cover data
- Slope data
- Terrain classification data
- Synthetic terrain generated for simulations
